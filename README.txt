YAYA'S HOT CHICKEN WEBSITE
===========================


HOW TO RUN THE WEBSITE
----------------------

1. Open the Yayas-Hot-Chicken-Website folder in Visual Studio Code.

2. Right-click index.html.

3. Click "Open with Live Server."


HOW TO EDIT THE MENU
--------------------

Open:

data.js

Find the menu item you want to change.

Example:

{
    name: "Loaded Fries",
    description: "",
    price: ""
}

Change the price like this:

{
    name: "Loaded Fries",
    description: "Crispy fries topped with chicken and sauce.",
    price: "$12.99"
}


HOW TO CHANGE BUSINESS HOURS
----------------------------

Open data.js.

Find:

hours:

Change "Add hours" to the correct hours.


HOW TO CHANGE PHONE NUMBER
--------------------------

Open data.js.

Find:

phone: ""

Put the restaurant phone number between the quotation marks.

Example:

phone: "(863) 555-1234"


HOW TO ADD THE LOGO
-------------------

Put the Yaya's logo inside the images folder.

Name the file:

logo.png

The website will automatically use it.


HOW TO SAVE CHANGES
-------------------

Press:

CTRL + S

If Live Server is running, refresh the browser if the change
does not automatically appear.


IMPORTANT
---------

index.html = website structure

style.css = colors and design

data.js = menu, prices, hours and restaurant information

script.js = website functions

images folder = restaurant pictures and logo
